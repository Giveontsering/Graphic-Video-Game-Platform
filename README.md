# 文图游戏生成器 · StoryForge

一个**完全 DIY 的图文/视频互动故事游戏平台**：纯本地网页，双击即玩，内置可视化编辑器——图片、视频、剧情分支、选项按钮，全部由你自己添加和更新，不需要写一行代码。

> 你可以把它当作一个"会点按钮就能更新"的互动小说 / 文图故事引擎：输入文本和图片（或视频），点击不同选项进入不同事件分支，一个属于自己的故事游戏就做好了。

## 🚀 快速开始

1. **游玩**：双击 `文图故事游戏.html`，直接体验内置示例故事《雾夜的城堡》；
2. **编辑**：点右上角「编辑」打开可视化编辑器——改正文、传图传视频、加选项、新建中文节点；
3. **固化**：编辑完点「导出数据文件」，把下载的 `story_data.js` 放回游戏文件夹覆盖，修改立即生效；
4. **手机玩**：双击 `手机预览.bat`，手机连同一 WiFi，用窗口里显示的地址访问。

## 🛠 如何制作你自己的故事

### 方式一：可视化编辑器（推荐新手）
在游戏页面点「编辑」：
- 顶部选择要编辑的节点，或输入新名字创建节点；
- 正文、选项（按钮文字 + 去向节点）、配图（上传图片/视频）全部可视化操作；
- 保存后立即生效，导出数据文件即可固化。

### 方式二：直接编辑文本源（推荐批量制作）
每个节点是一个 `story\节点名.md` 文件，格式非常简单：

```markdown
# 章节标题

正文第一段……
正文第二段……

[选项按钮文字] -> 目标节点名
[另一个选项] -> 另一个节点名

图片: 文件名.jpg        ← 可选，也可不写
```

规则：
- **文件名 = 节点名**（中文即可），游戏从 `story\序章.md` 或 `story\start.md` 开始；
- **选项行**格式：`[按钮文字] -> 节点名`，一行一个选项，写多少都行；
- **配图**：不写「图片:」行时，自动匹配 `assets\节点名.jpg`（支持 jpg/png/webp/gif/mp4/webm/mov）；
- 改完后运行 `更新游戏.bat`，自动生成新的 `story_data.js`。

## 📱 局域网手机预览

1. 电脑双击 `手机预览.bat`（保持黑窗口开启）；
2. 电脑和手机连**同一个 WiFi / 热点**；
3. 手机浏览器打开窗口里显示的地址（如 `http://192.168.1.x:8080/文图故事游戏.html`），即可游玩和编辑。

> 注意：手机与电脑的编辑数据各自存在各设备浏览器里，跨设备查看修改内容需先「导出数据文件」再拷贝到另一台设备的游戏文件夹覆盖。

## ⚙️ 技术说明

- 纯原生 **HTML + CSS + JavaScript** 单文件，无框架、无构建工具、无后端；
- 编辑内容存储于浏览器 **IndexedDB / localStorage**，导出时内嵌为数据文件（`story_data.js`）；
- 媒体（图片/视频）可上传到浏览器存储，也可放入 `assets/` 文件夹按文件名引用；
- 兼容 Chrome / Edge / Safari 及主流手机浏览器；
- 全中文命名体系：节点、选项、数据文件全部中文，零上手成本。

## ❓ 常见问题

**Q：手机看不到电脑编辑的内容？**
电脑编辑后点「导出数据文件」，将 `story_data.js` 覆盖到游戏文件夹；手机端用**无痕模式**或清除缓存后重新打开。

**Q：视频播放不了或闪一下就消失？**
请使用 H.264 编码的 `.mp4` 或 `.webm` 格式；个别手机拍摄的 HEVC 视频浏览器不支持，转码后再上传。

**Q：换电脑后内容丢了？**
内容存在浏览器本地，请导出 `story_data.js`；若配图是 `assets/` 文件夹引用，连同 `assets/` 一起拷贝即可。

**Q：想清空所有修改、回到初始内容？**
在编辑面板点「清除本地修改」，或删除浏览器里该站点的本地存储数据。
